12. Configuración TEMPLATES

TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [],
        'APP_DIRS': True,
        'OPTIONS': {
            'context_processors': [
                'django.template.context_processors.request',
                'django.contrib.auth.context_processors.auth',
                'django.contrib.messages.context_processors.messages',
            ],
        },
    },
]

BACKEND: motor de plantillas utilizado por Django.

DIRS: lista de carpetas donde Django buscará plantillas.

APP_DIRS: permite buscar plantillas dentro de cada aplicación.

OPTIONS: configuraciones adicionales del motor de plantillas.

13. Componentes

Motor

Administra el sistema de plantillas de Django.

Plantilla

Representa una plantilla compilada.

Contexto

Contiene los datos enviados a la plantilla.

Cargadoras

Buscan y cargan plantillas automáticamente.

Procesadores de contexto

Agregan datos comunes automáticamente a las plantillas.

14. Uso de get_template()

from django.template.loader import get_template

template = get_template("inicio.html")

Carga una plantilla específica.

15. Uso de render_to_string()

from django.template.loader import render_to_string

html = render_to_string(
    "inicio.html",
    {"nombre": "Oscar"}
)

Renderiza una plantilla y devuelve un string HTML.

16. Uso de engines

from django.template import engines

django_engine = engines["django"]

template = django_engine.from_string(
    "Hola {{ nombre }}"
)

Permite usar motores de plantillas directamente.

17. Jinja2

pip install Jinja2

Jinja2 es un motor alternativo de plantillas compatible con Django.

Soporta funciones, filtros y variables globales.

18. Advertencia de Seguridad

No se deben permitir plantillas creadas por usuarios no confiables, porque podrían ejecutar ataques XSS o acceder a información sensible.

19. Context Processor

Aplicación global: {{ app_global }}

Usuario global: {{ usuario_global }}

Estas variables están disponibles automáticamente en todas las plantillas del proyecto.
